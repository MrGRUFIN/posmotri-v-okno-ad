# Посмотри в окно

https://github.com/MrGRUFIN/posmotri-v-okno-ad

Учебный проект: CSS-оформление приложения с поиском видеороликов по городу и времени суток.

## Запуск

Откройте `index.html` в современном браузере. Для загрузки видео требуется подключение к интернету и доступность API Практикума.

В проекте используются Flexbox, локальные шрифты, кастомные чекбоксы, состояния наведения, нажатия и клавиатурного фокуса. HTML, JavaScript, прелоадер и блок ошибки сохранены из официальной заготовки.
